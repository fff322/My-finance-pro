Мои Финансы — Таблица
Установка: откройте через HTTPS и выберите «Добавить на главный экран».
Данные хранятся на устройстве в LocalStorage.
Есть добавление, редактирование и удаление строк, фильтры, поиск, экспорт и импорт JSON.

Новая функция: автоматические итоги по каждому месяцу — доходы, расходы и баланс, плюс общий итог. Нажатие на месяц сразу фильтрует таблицу по этому месяцу.

Новая функция: цель месяца. Нажмите «🎯 Цель месяца», задайте сумму накопления. Прогресс считается автоматически как (доходы − расходы) за выбранный месяц. Цель можно удалить кнопкой ×.
