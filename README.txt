МОИ ФИНАНСЫ — PWA

1. Откройте index.html через веб-хостинг, поддерживающий HTTPS.
2. На Android откройте адрес в Chrome.
3. Выберите «Добавить на главный экран» / «Установить приложение».
4. Данные операций сохраняются локально в браузере телефона.
5. Для работы Service Worker и установки PWA нужен HTTPS (или localhost).

Функции:
- доходы и расходы
- категории
- баланс
- история
- месячная статистика
- график
- тёмная тема
- офлайн-кэш после первого открытия
